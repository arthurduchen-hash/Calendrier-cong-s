Notifications

Déclenche une notification du navigateur au moment de l'alerte choisie sur un évènement (voir la modale de création). Ne fonctionne que si cet onglet reste ouvert et au premier plan dans le navigateur — pas de notification si le calendrier est fermé, en arrière-plan, ou sur iPhone/iPad hors PWA installée sur l'écran d'accueil (Safari mobile ne supporte pas les notifications web dans un onglet classique). Utilisez "Tester la notification" pour vérifier que ça fonctionne sur cet appareil, indépendamment de tout évènement.

Synchronisation Google Sheet

Colle ici l'URL obtenue après avoir déployé le script Google Apps Script fourni (Code.gs). Utilise la même URL sur tous tes appareils pour qu'ils partagent les mêmes données. Sans URL, le calendrier fonctionne comme avant, uniquement en local.
Les données sont enregistrées automatiquement dans le stockage local de ce navigateur. Si une synchronisation Google Sheet est configurée (Paramètres), elles sont aussi envoyées vers le Sheet pour être accessibles depuis tes autres appareils. Pensez à exporter régulièrement une sauvegarde JSON.
